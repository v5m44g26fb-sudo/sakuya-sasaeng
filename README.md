# サクヤのサセンやってる件

NCT WISHのサクヤを推す成人ファンの「なお」が、公開情報の収集から始めて、推しの私生活を追う「サセン（사생팬）」の世界に少しずつ足を踏み入れていく、スマホ風SNSファンゲーム。

『サクヤと熱愛バレた件』（熱愛バレ編）とは別世界の物語で、UI・実装の器をそちらから移植し、物語・セリフは全て新規に書き起こした。

## プレイ

https://v5m44g26fb-sudo.github.io/sakuya-sasaeng/

## 物語

- 時期：2026年11月〜2027年3月。クライマックスは2027年3月5日〜7日のGLION ARENA KOBE公演
- 章立て（全10話）は、サセンの行動のエスカレーション段階がモチーフ：
  公開情報の収集 → 出待ち → 空港 → 追跡 → 情報の購入 → 踏み込み → 警告 → 神戸
- 登場人物：先輩サセンのミント、仲間のはる、情報屋K。サクヤ本人との直接のやり取りはない（追う側の物語）
- トーン：綱渡りのブラックコメディ寄りの日常。バレ度が上がる場面はシリアスに寄せる

## システム

- ゲージ3本：接近度／バレ度／資金。選択で変動し、最終選択（act）と合わせてエンディングが分岐
- エンディング3種：出禁END／卒業END／気づかれるEND（到達後はエンディングコレクションで読み返し＋後日談）
- エンディング後は、情報屋Kとのフリーチャットが解放される
- BGM・効果音はWeb Audio合成のオリジナル（著作権のある楽曲は不使用）。ボイス収録なし
- セーブは端末内（localStorage）に自動保存
